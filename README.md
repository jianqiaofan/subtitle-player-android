# 字幕播放器（Android）

第 1 期：本地字幕学习播放器。在电脑上用[桌面版](https://github.com/jianqiaofan/subtitle-player)下载视频、生成字幕，把**同一文件夹**里的媒体和 `.srt` / `.vtt` 拷到手机，在本 App 里跟读、跳转、编辑字幕并写回文件。

不做：视频下载、Whisper 转写、AI 笔记。字幕和标签可以按账号同步到 `https://subtitle.gcsfg.work`，视频文件仍留在手机上。

产品规格见 [`AGENTS.md`](AGENTS.md)。云同步见 [`安卓交接-云同步-2026-09-29.md`](安卓交接-云同步-2026-09-29.md)。应用内更新见 [`安卓交接-应用内更新-2026-09-29.md`](安卓交接-应用内更新-2026-09-29.md)。

## 当前进度

第 1 期功能已接通：选择学习文件夹、播放、字幕跳转/高亮/跟读循环、倍速、倒计时、复制、编辑字幕并写回文件。

## 如何把电脑文件放到手机

1. 媒体和字幕放在同一目录即可，例如：

   ```
   某课程/
     课程名.mp4
     课程名_中文.srt
     课程名_英文.srt
     课程名_同步.srt
   ```

2. 用 USB、网盘或无线传输，拷到手机的 Download、Movies 等目录。
3. 在 App 里点「选择文件夹」，授权该目录后即可列出媒体。打开视频时，字幕、标签、哈希和播放记录会收进旁边的 `课程名.mp4.data`。转录工具新生成的字幕如果还在视频旁边，下次打开会搬进去。

支持的媒体扩展名见 `AGENTS.md` 第 6.1 节。字幕只认外部 `.srt` / `.vtt`。

标签和备注写在配套文件夹里的 `字幕文件名.tags.json`（例如 `课程名.mp4.data/课程名_中文.srt.tags.json`），不改字幕正文。从电脑拷贝时，字幕和标签可以先放在视频旁边，打开后会进入配套文件夹。没有字幕时，列表改成按步距分段的时间线，不生成字幕文件；时间线上的标签记在 `课程名_时间线.srt.tags.json`。播放页可以打标签、筛选、同步标签文件；「批量同步标签」一次处理一个视频文件夹（含子文件夹）里的多部视频。「提取全部标签」把各文件夹里的标签平铺复制到另一个文件夹，方便拷到另一台设备后再批量同步回去。来源文件不会被修改。U 盘上的这三项仍是追加合并，和云端按时间合并的标签不是同一条路径。观看中改过字幕或标签，离开视频、换视频或放到结尾时会询问是否同步。播放页「学习记录」按设备时区列出每一次播放。

## 云同步

媒体库顶栏「账号」里填写用户名、密码。默认服务器是 `https://subtitle.gcsfg.work`。和电脑使用同一个用户名，就是同一个用户。

- 第一次用播放器打开视频时，在 `视频全名.data` 里生成 `视频全名.videohash.json`。云端靠这个内容哈希认出视频，不看文件名。播放记录在同一个文件夹的 `playback.json`，只属于当前登录的账号。
- 已登录时，打开视频会在后台检查自己的字幕和标签。离线或服务器连不上时不弹错误。本地一份有效字幕都没有时，才可以选择别人共享的字幕。
- 「云端管理」可以查看、删除自己的字幕和标签，修改字幕是否共享，并从字幕文件或文件夹上传。上传字幕前会询问共享还是仅自己使用。没有哈希文件会拒绝上传并说明原因。
- 标签上传只发送自上次同步以来的变化，取消标签会写成删除操作，不会把整份标签覆盖到云端。

## 应用内更新

账号页有「安装更新」。点下去才会读取 `https://subtitle.gcsfg.work/releases/latest.json`，不会在启动时下载。服务器上的 `versionCode` 更大时，先展示版本名和说明，确认后再下载。安装包地址必须是 `https://subtitle.gcsfg.work/releases/` 下的文件。下载后核对 SHA-256，不一致就删除并提示更新包损坏。校验通过后交给系统安装器，需要先允许本应用「安装未知应用」。

调试包和正式包使用同一把签名密钥，放在仓库上一级目录的 `subtitle-player-android-signing`，不进入 git。手机上如果已经装着另一把密钥打的旧包，第一次要卸载后再安装；之后用「安装更新」覆盖即可。

打包并上传的步骤见 [`发布更新.md`](发布更新.md)。在对话里要求打包上传时，执行 `scripts/publish-release.ps1`。

## 在 Android Studio 里运行

1. 安装 [Android Studio](https://developer.android.com/studio)（需 Android SDK，compileSdk 37）。
2. 打开本仓库根目录，等待 Gradle 同步。
3. 用 USB 连接 Redmi Note 13 Pro（或模拟器），运行 `app`。

包名：`com.jianqiaofan.subtitleplayer`  
最低系统：Android 8.0（API 26）  
云同步需要联网。播放本地文件本身不依赖网络。
